# Plotting and notebook workflow

The **four curated notebooks** use the wide CSVs generated by the analysis
pipeline. They contain figure selection, labels, and scientific interpretation,
not contact counting, graph construction, aggregation or a copy of the plot
implementations.

| Notebook | Question | Inputs |
| --- | --- | --- |
| [01_validation.ipynb](01_validation.ipynb) | Single-chain MFE, precision/recall, Rg | Validation sweep |
| [02_reentrance.ipynb](02_reentrance.ipynb) | **RQ1 — Reentrant clustering** | 50b_reentrant_full |
| [03_length.ipynb](03_length.ipynb) | **RQ2 — RNA length**, including scrambled controls | 51a_repeat_number, 51b_repeat_number_rand |
| [04_mixtures.ipynb](04_mixtures.ipynb) | **RQ3 — CAG10/CAG47 mixtures** | 52b_from_frame, plus 51a repeat-length pure controls |

## Quick start

1. Install `analysis/requirements.txt` and open Jupyter from the
   repository checkout.
2. Point the notebook data loader at the existing `analysis_results/` directory
   on the HPC system (or at a locally mounted copy of that same directory).
   For example, the full-sweep tables are already located at
   `analysis_results/50b_reentrant_full/summary.csv` and `replicates.csv`.
   No additional `data/processed/` staging directory is required.
3. Open `jupyter lab analysis/notebooks/` and execute each notebook top to
   bottom. The default scientific figures need only those CSV files; no
   production GSD, NPZ or SQLite files are required.
4. Only when original trajectory data are available, turn on the optional
   projection/PyVis export cells. Published PNGs and HTMLs can be viewed
   separately without running those cells.

The notebooks never need to import HOOMD-blue. The base plotting dependencies
are `pandas`, `numpy`, `matplotlib` and `seaborn`. The optional GSD
projections additionally need `gsd` and `scipy`.
The optional HTML molecular network needs `pyvis`.

## Module layout

- `src/plots/style.py` — PlotStyle dataclass, human-readable labels,
  seven-bin palette, ranked-category and RNA-species colors
- `src/plots/data.py` — load one sweep's wide tables, select conditions,
  `melt_metrics()` on demand, and construct independent scramble units
- `src/plots/figures.py` — Matplotlib/Seaborn axes-first, reusable
  scientific summary plots, including mixture contact composition
- `src/plots/panels.py` — `panels_by()` / axes grids
- `src/plots/projections.py` — FINAL-frame XY density projections from
  GSD, reusable with RQ1 rows = stiffness or RQ2 rows = repeat count
- `src/plots/framewise.py` — time-series plotting functions **kept outside
  the curated notebooks**, because framewise CSVs are not exported by default
- `src/plots/networks.py` — optional PyVis export from saved
  molecule-contact graph NPZ (standalone HTML)
- `src/plots/diagnostic.py` — older full diagnostic / RDF helpers,
  preserved separately, not part of the main plotting workflow

## Your existing functools.partial / PlotStyle pattern

Every reusable plot function takes `(df, ax, *, style, ...)`. A notebook
pins presentation choices with `partial`, while the panel helper supplies
the data subset and Matplotlib Axes:

~~~python
from functools import partial
from dataclasses import replace
from src.plots.style import PlotStyle
from src.plots.figures import plot_cluster_bins
from src.plots.panels import panels_by

style = replace(PlotStyle(), font_size=11, stack_alpha=0.95)
draw = partial(plot_cluster_bins, scheme="molecule_count", style=style)
fig, axes = panels_by(
    summary, by="angle_k_ppp", plot_fn=draw, style=style,
    title="Reentrant cluster-size distribution"
)
~~~

Use `style.label("E_att")` for LaTeX axes and `style.label_map`,
`style.stack_colors`, `style.rank_colors`, `style.contact_colors`,
or `style.species_colors` for appearance. Do not change scientific
calculations when changing figure aesthetics.

## Wide tables and reshaping

The source of truth remains the wide per-replicate and condition CSVs.
Use `melt_metrics(df, metrics, id_vars=...)` only for plots that naturally
treat metric name as a categorical variable. Do **not** melt every metric
in every notebook as a prerequisite. Seaborn handles independent replicate
box/strip plots; Matplotlib handles stacked fraction bars.

RQ2 scientific comparisons must use **independent scrambled sequence units**,
not repeated trajectories of a single scramble. The helper
`independent_units()` enforces the sequence-level grouping for exploratory
plots; adjust statistical-testing families explicitly in the notebook.

## Optional spatial and network figures

The RQ1 and RQ2 notebooks each contain an opt-in `SHOW_PROJECTIONS = False`
cell. Turn it on only with the original GSD sweeps accessible. The clean
projection reproduces the **representative final XY frame**, not pooled
densities, 1D profiles or RDFs. Both plots use the same code and shared
color normalization across the grid.

RQ3 can export one standalone HTML network per attraction strength
(`E_att = 2, 4, 8`) from the corresponding graph NPZ and molecule lookup.
Each network uses the final cached trajectory frame, excludes unconnected
molecules, colors RNA species by node and contact type by edge, and keeps
physics disabled. `EXPORT_PYVIS = False` is the default.

The Rg panel in the single-chain validation notebook plots each replicate's
final-10%-window mean Rg and the **mean ± standard deviation across
replicates**, entirely from `replicates.csv` and `summary.csv`.
The earlier frame-percentile plot (final 20%) remains available in the
`load_rg_frames` helper but is no longer required by the public notebook.

GitHub renders notebook Markdown and static images but not live PyVis
JavaScript. Keep published HTML files separately, link to them from the
Markdown, and open them locally for interactivity.

Optional framewise trace helpers remain in `src/plots/framewise.py` and are
**not included in the four notebooks**.

## Reproducibility and testing

~~~bash
python -m pytest analysis/tests -q
~~~

Tests cover the four analysis profiles and plotting utilities with synthetic
data. Review the compiled CSVs for full sweeps before interpreting results.
The legacy notebooks and exported HTML under `notebooks/` remain intact
as references; this new workflow does not depend on their outputs.

## Automatic figure exports

Each curated notebook sets `SAVE_FIGURES = True` in its setup cell and
saves PNGs beside the relevant sweep under
`analysis_results/<sweep>/figures/`. Set `SAVE_FIGURES = False` to
avoid writing files. `RNA_ANALYSIS_RESULTS_ROOT` overrides the output root.
The RQ2 notebook writes joint plots using the periodic sweep's figures
folder; its figures can still use both periodic and scrambled CSVs.
Optional GSD projections retain a separate input trajectory path and are
saved as `reentrance_xy.png` or `length_xy.png` when enabled.

These generated files can be included in the repository only if the
`analysis_results` directory lies within the checkout (or selected files
are copied into the checkout). The `.gitignore` allows reviewed
`summary.csv`, `replicates.csv`, and PNG/PDF files under `figures/`
but not large intermediates or SQLite checkpoints.
